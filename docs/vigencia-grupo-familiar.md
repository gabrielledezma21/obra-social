# Vigencia del grupo familiar

La fecha de baja del titular gobierna la vigencia máxima del grupo familiar.

- Si el titular recibe una fecha de baja, esa fecha se propaga automáticamente a todos sus familiares.
- Si se modifica o elimina la fecha de baja del titular, el cambio se replica al grupo.
- Si se crea un familiar bajo un titular que ya tiene una baja programada, el familiar hereda esa misma fecha.
- La invalidación de caché incluye a todos los integrantes afectados.

Esta regla se aplica en backend para no depender de que cada cliente envíe una bandera adicional.
